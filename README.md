# oas-for-mac

**原仓库地址：[OnmyojiAutoScript](https://github.com/runhey/OnmyojiAutoScript)**



1. 环境
   - mac0SSequoia 15.7（M 系列芯片）
   - python 3.13.3
2. 安装

```shell
pip install -r requirements.txt
python server.py
```

3. 使用（配合 [OASX](https://github.com/runhey/OASX) 使用）
   - 自行使用 `flutter` 编译对应客户端
   - 通过 Release 下载编译好的 mac 客户端、web 端、ios 端
